SECURITY
========

  Independent checks, not a repair sequence. Pick the relevant one.

CHECKS
------
  01  Check Microsoft Defender
      - Antivirus configuration, status and available detection information.
  02  List Local Administrators
      - Members of the local Administrators group and related audit
        information.
  03  Check Encryption and Firmware
      - Encryption, TPM, Secure Boot and firmware findings.

NOTES
-----
  - Read each guide for administrator requirements and limits.
  - No tool here turns protection off or changes group membership.
