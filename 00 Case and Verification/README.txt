CASE AND VERIFICATION
=====================

  Order: 01 -> 02 (Before) -> repair -> 02 (After) -> 03 -> 04.

TOOLS
-----
  01  Start Case and Check Readiness
      - Describe the issue. Save the Case folder path printed in the result.
      - Read the account, pending restart, servicing and free-space findings.

  02  Capture Before or After Checks
      - Choose the case, area and Before. Do this before any repair.
      - After the relevant repair or manual restart, repeat using After.
      - Use the same area, target and affected account for a useful
        comparison.

  03  Compare Checks and Record Outcome
      - Compare the newest matching snapshots and record your observed
        outcome.
      - Changed numbers or a running service alone do not prove the problem
        fixed.

  04  Export Case for Review
      - Review the listed reports, then create a local ZIP for handoff.
      - Reports may include user, PC, file and server names. Review before
        sharing.

NOTES
-----
  - New repair tools accept -CasePath to copy results into the case.
  - For older tools, select the case as -ReportPath or -LogPath as supported.
  - No case tool automatically starts a repair, restarts Windows or uploads
    data.
