OUTLOOK - CHOOSE THE APP FIRST
==============================

01 Classic Outlook
  Check sync and the current mail view before considering an OST rebuild.

02 New Outlook
  Check the app, local data and Microsoft service access before a reset.

Each app folder has its own 01 check and 02 repair.
Run the check in the affected user's session.

Filters, sorting, Work Offline or service issues may need no cache repair.
