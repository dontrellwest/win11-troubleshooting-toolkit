OUTLOOK
=======

  Choose the app first: 01 Classic Outlook or 02 New Outlook. Each folder
  starts with its own check and lists its repairs after it.

FOLDERS
-------
  01  Classic Outlook
      - Check sync and the current mail view before considering an OST
        rebuild.
  02  New Outlook
      - Check the app, local data and Microsoft service access before a
        reset.

NOTES
-----
  - Run the check in the affected user's session.
  - Compare missing mail with Outlook on the web.
  - Filters, sorting, Work Offline or service issues may need no cache repair.
  - Read the selected repair guide before changing any local mail data.
